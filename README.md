# Учебный проект: генератор предсказаний на C

Программа демонстрирует базовые приёмы работы с массивами строк, генерацией случайных чисел.

## Реализация

- **Массивы строк**: предсказания разделены на три части (начало, середина, конец) и хранятся в отдельных массивах `const char *[]`.
- **Подсчёт длины массивов**: используется выражение `sizeof(arr) / sizeof(arr[0])` для получения количества элементов.
- **Случайность**: инициализация генератора через `srand(time(NULL))`, выбор индексов через `rand() % size`.
- **Локализация**: `setlocale(LC_ALL, "")` позволяет корректно отображать кириллицу в терминале.
